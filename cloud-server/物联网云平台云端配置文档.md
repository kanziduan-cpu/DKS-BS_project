# 物联网云平台云端配置文档

## 项目概述

基于阿里云 ECS 的物联网云平台系统，实现 STM32 边缘端与 Android 移动端的数据交互、存储和调度。

## 系统架构

```
STM32单片机 (MQTT) ↔ 云端服务器 (HTTP/WebSocket) ↔ 手机App
```

## API接口文档

### 传感器数据接口

#### 获取最新传感器数据
```
GET /api/sensor/latest/:deviceId
```
**示例**: `curl http://120.55.113.226:3001/api/sensor/latest/STM32_MAIN`

#### 获取历史数据
```
GET /api/sensor/history/:deviceId?limit=100
```
**示例**: `curl http://120.55.113.226:3001/api/sensor/history/STM32_MAIN?limit=10`

#### 获取指定时间范围数据
```
GET /api/sensor/range/:deviceId?start=2026-03-01&end=2026-03-12
```

### 设备控制接口

#### 获取设备状态
```
GET /api/device/status/:deviceId
```

#### 发送控制指令
```
POST /api/control/command
```
**请求体**:
```json
{
  "device_id": "device001",
  "command": "control_servo",
  "params": { "angle": 90 }
}
```

### 报警管理接口

#### 获取报警记录
```
GET /api/alarms/:deviceId
```

#### 标记报警已解决
```
PUT /api/alarms/:id/resolve
```

```json
  "params": { "angle": 90 }
}
```

## 数据库表结构

### 1. sensor_data (传感器数据表)
```sql
CREATE TABLE IF NOT EXISTS sensor_data (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT NOT NULL,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    temperature REAL,
    humidity REAL,
    co REAL,
    co2 REAL,
    formaldehyde REAL,
    water_level REAL,
    vibration INTEGER,
    tilt_x REAL,
    tilt_y REAL,
    tilt_z REAL
);
```

### 2. control_commands (控制指令表)
```sql
CREATE TABLE IF NOT EXISTS control_commands (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT NOT NULL,
    command TEXT NOT NULL,
    params TEXT,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    status TEXT DEFAULT 'pending'
);
```

### 3. alarms (报警记录表)
```sql
CREATE TABLE IF NOT EXISTS alarms (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT NOT NULL,
    type TEXT NOT NULL,
    message TEXT,
    severity TEXT DEFAULT 'warning',
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    resolved INTEGER DEFAULT 0
);
```

### 4. device_status (设备状态表)
```sql
CREATE TABLE IF NOT EXISTS device_status (
    device_id TEXT PRIMARY KEY,
    last_update DATETIME DEFAULT CURRENT_TIMESTAMP,
    ventilation INTEGER DEFAULT 0,
    dehumidifier INTEGER DEFAULT 0,
    servo_angle INTEGER DEFAULT 0,
    alarm_active INTEGER DEFAULT 0
);
```

## 防火墙配置

### Ubuntu (UFW)
```bash
ufw allow 1883/tcp    # MQTT 服务
ufw allow 3001/tcp    # API 服务 + WebSocket
ufw reload
```

### CentOS (firewalld)
```bash
firewall-cmd --zone=public --add-port=1883/tcp --permanent
firewall-cmd --zone=public --add-port=3001/tcp --permanent
firewall-cmd --reload
```

### 阿里云安全组
| 协议类型 | 端口范围 | 授权对象 | 描述 |
|---------|----------|----------|------|
| TCP | 1883/1883 | 0.0.0.0/0 | MQTT 服务 |
| TCP | 3001/3001 | 0.0.0.0/0 | API 服务 + WebSocket |

## 故障排查

### 常见问题

#### 1. 端口被占用
```bash
# 检查端口占用
netstat -tlnp | grep 3001

# 杀死占用进程
kill -9 $(lsof -t -i:3001)
```

#### 2. 服务无法启动
```bash
# 查看详细错误
node server.js

# 检查依赖
cd /opt/warehouse-monitor/cloud-server
npm list
```

#### 3. MQTT连接失败
```bash
# 测试MQTT连接
mosquitto_sub -h localhost -p 1883 -t "sensor/#" -v
```
