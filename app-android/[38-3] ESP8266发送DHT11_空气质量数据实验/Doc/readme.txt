【*】程序简介

-工程名称		：ESP8266发送DHT11_空气质量数据实验
-实验平台  		：野火 STM32F103C8T6-STM32开发板  

【 ！】功能简介：

使用ESP8266发送DHT11和空气质量数据给TCP服务器

【 ！】实验操作：

    1.修改app_esp8266.h文件里wifi和服务器IP（即你电脑的 IP 地址）
	2.打开串口调试助手：设置串口号、配置波特率为115200
    3.打开网络调试助手：设置协议类型为 TCP Server、IP 地址、端口号并启动监听(可从Doc文件夹查看如何配置)
    4.编译并下载程序到开发板
    5.查看串口打印

/*********************************************************************************************/

【*】 引脚分配

KEY1->PA0	按键按下为高电平 	核心板板载默认下拉且硬件有消抖
NRST->NRST	按键按下为低电平 	核心板板载默认上拉且硬件有消抖

LED_R->LED1->PA1	核心板板载LED灯低电平亮 

DEBUG_TX->USART1_TXD->PA9		PA9作为USART1的TXD	核心板默认使用 PA9 做 DEBUG_TX  
DEBUG_RX->USART1_RXD->PA10		PA10作为USART1的RXD	核心板默认使用 PA10 做 DEBUG_RX

		 
ESP8266_TX->USART3_TXD->PB10		PB10作为USART3的TXD	外部设备串口_TX
ESP8266_RX->USART3_RXD->PB11		PB11作为USART3的RXD	外部设备串口_RX
ESP8266_RST->PB9                    复位引脚，低电平有效
ESP8266_IO->PB8                     默认上拉为运行模式，外部拉低为下载模式

DHT11_DATA->PB12				DHT11温湿度传感器数字电平输入，数据通过一定电平规则(协议)变化，传感器模块默认上拉

MQ135_AO->PA4					PA4作为空气质量检测传感器模拟信号输入

/*********************************************************************************************/

【*】程序描述：

< main.c >

	1.初始化USART、LED、DHT11、MQ135和ESP8266对应的GPIO、端口等配置
	2.使用一个红灯作为程序正常运行的心率灯
	3.串口调试助手发送指令给开发板，开发板接收串口调试助手发送的数据，再把数据转发给ESP8266
	4.开发板接收ESP8266发回的数据，再把数据发给串口调试助手显示
    5.调用函数发送AT指令，配置连接WIFI与透传
    6.执行DHT11和MQ135采集以及发送到TCP服务器任务
