# 多传感器监控系统 - 项目总结

## 项目概述
本项目基于STM32F103C8T6开发板，实现了一个完整的多传感器监控系统，包括温湿度、空气质量、姿态、倾斜、震动检测、声光报警和自动控制通风等功能。

## 硬件配置
- 主控：STM32F103C8T6
- 通信：ESP8266 WiFi模块
- 传感器：
  - DHT11：温湿度传感器
  - MQ135：空气质量传感器（ADC读取）
  - MPU6050：姿态传感器（6轴加速度计+陀螺仪）
  - 倾斜传感器：检测地面下沉导致的倾斜
- 执行器：
  - SG90舵机：控制通风口开合
  - LED：视觉报警
  - 蜂鸣器：声音报警

## 新增功能模块

### 1. 倾斜传感器模块 (User/tilt/)
**文件：**
- `bsp_gpio_tilt.h` - 倾斜传感器头文件
- `bsp_gpio_tilt.c` - 倾斜传感器驱动实现

**功能：**
- 检测设备是否发生倾斜
- 提供状态查询和标志清除功能
- 用于监测地面下沉等结构性问题

**使用方法：**
```c
TILT_Init();                              // 初始化
uint8_t status = TILT_ReadStatus();       // 读取状态
TILT_ClearFlag();                         // 清除标志
```

### 2. 声光报警系统模块 (User/alarm/)
**文件：**
- `bsp_alarm.h` - 报警系统头文件
- `bsp_alarm.c` - 报警系统实现

**功能：**
- 多级报警系统（低、中、高、严重）
- 自动检测温度、湿度、空气质量、震动、倾斜异常
- LED闪烁和蜂鸣器报警
- 根据报警级别自动调整报警频率

**报警类型：**
- ALARM_TEMPERATURE - 温度异常
- ALARM_HUMIDITY - 湿度异常
- ALARM_AIR_QUALITY - 空气质量异常
- ALARM_SHAKE - 震动检测
- ALARM_TILT - 倾斜检测

**使用方法：**
```c
ALARM_Init();                                            // 初始化
ALARM_CheckTemperature(temp, 15.0f, 35.0f);              // 检查温度
ALARM_CheckHumidity(humidity, 30.0f, 80.0f);             // 检查湿度
ALARM_CheckAirQuality(aqi, 150);                         // 检查空气质量
ALARM_CheckShake(shake_detected);                         // 检查震动
ALARM_CheckTilt(tilt_detected);                          // 检查倾斜
ALARM_Update();                                           // 更新报警状态
```

### 3. 自动控制系统模块 (User/control/)
**文件：**
- `bsp_control.h` - 控制系统头文件
- `bsp_control.c` - 控制系统实现

**功能：**
- MPU6050与舵机联动控制
- 自动/手动控制模式切换
- 根据传感器数据自动控制通风口
- 可配置的触发阈值和动作延迟

**控制模式：**
- CONTROL_MANUAL - 手动控制
- CONTROL_AUTO - 自动控制

**触发条件：**
- TRIGGER_SHAKE - 震动触发（打开通风口）
- TRIGGER_TILT - 倾斜触发（打开通风口）
- TRIGGER_AIR_QUALITY - 空气质量差（打开通风口）
- TRIGGER_TEMPERATURE - 温度异常（根据情况开/关）

**使用方法：**
```c
CONTROL_Init();                                          // 初始化
CONTROL_SetMode(CONTROL_AUTO);                           // 设置为自动模式
CONTROL_Update();                                        // 更新控制系统
CONTROL_SetVentAngle(90);                                // 手动设置角度（0-180度）
```

### 4. 扩展的ESP8266数据上传 (User/esp8266/)
**新增函数：**
- `ESP8266_SendMPU6050DataTest()` - 发送MPU6050姿态数据
- `ESP8266_SendTiltDataTest()` - 发送倾斜传感器数据
- `ESP8266_SendAllSensorData()` - 发送所有传感器综合数据

**数据格式（JSON）：**
```json
{
  "sensor": "MPU6050",
  "accel": {"x": 0.12, "y": -0.05, "z": 0.98},
  "gyro": {"x": 1.23, "y": -0.45, "z": 0.12},
  "shake": 0

{
  "sensor": "TILT",
  "status": 0,
  "detected": false
}

{
  "system": "MULTI_SENSOR",
  "dht11": {"temperature": 25.5, "humidity": 60.0},
  "air_quality": 85,
  "mpu6050": {
    "accel": {"x": 0.12, "y": -0.05, "z": 0.98},
    "gyro": {"x": 1.23, "y": -0.45, "z": 0.12}
  },
  "tilt": 0,
  "vent": 1,
  "alarm": 0
}
```

## 主程序流程

### 初始化阶段：
1. 硬件初始化（LED、串口、ADC等）
2. 传感器初始化（DHT11、MPU6050、倾斜传感器）
3. 报警系统初始化
4. 控制系统初始化
5. 舵机和蜂鸣器初始化

### 主循环：
1. 读取传感器数据
2. 检测异常情况（温度、湿度、空气质量、震动、倾斜）
3. 更新报警系统（LED闪烁、蜂鸣器）
4. 更新控制系统（自动控制通风口）
5. 通过ESP8266上传数据

## 系统特性

### 1. 智能报警
- 多级报警系统，根据严重程度调整报警频率
- 自动识别多种异常情况
- 声光双重报警，确保及时提醒

### 2. 自动控制
- 检测到震动或倾斜时自动打开通风口
- 空气质量差时自动通风
- 温度过高时降温，过低时保温
- 支持手动/自动模式切换

### 3. 数据上传
- 支持单独上传各传感器数据
- 支持上传综合数据（所有传感器+系统状态）
- JSON格式数据，易于解析

### 4. 震动检测
- 利用MPU6050的加速度数据检测震动
- 四级震动严重度分类
- 可配置触发阈值

## 配置参数

### 报警阈值（可在代码中修改）：
- 温度范围：15°C - 35°C
- 湿度范围：30% - 80%
- 空气质量阈值：150
- 震动触发级别：中等以上（≥2）
- 倾斜检测：检测到即触发

### 舵机控制：
- 通风口打开角度：90度
- 通风口关闭角度：0度
- 动作延迟：1000ms（避免频繁动作）

### 报警频率：
- 低级：LED 1秒间隔，蜂鸣器 2秒间隔
- 中级：LED 0.5秒间隔，蜂鸣器 1秒间隔
- 高级：LED 0.25秒间隔，蜂鸣器 0.5秒间隔
- 严重：LED 0.1秒间隔，蜂鸣器 0.2秒间隔

## 使用说明

### 1. 编译和下载
- 使用Keil MDK或IAR编译项目
- 通过ST-Link或J-Link下载到开发板

### 2. 配置WiFi
- 在ESP8266相关代码中配置WiFi名称和密码
- 配置服务器IP和端口

### 3. 运行
- 上电后系统自动初始化
- 串口输出调试信息
- ESP8266自动连接WiFi并开始上传数据

### 4. 测试
- 使用热源测试温度报警
- 使用湿源测试湿度报警
- 使用烟雾测试空气质量报警
- 轻敲设备测试震动报警
- 倾斜设备测试倾斜报警
- 观察舵机自动控制通风口

## 注意事项

1. **硬件连接：** 确保所有传感器正确连接，检查电源和地线
2. **I2C通信：** MPU6050使用I2C通信，确保上拉电阻正常
3. **舵机电源：** 舵机可能需要外部电源，避免从STM32取电
4. **ESP8266配置：** 确保WiFi名称和密码正确
5. **数据频率：** 根据实际需求调整数据上传频率，避免频繁上传

## 扩展建议

1. **添加水位传感器：** 项目中已预留水位传感器接口
2. **OLED显示：** 添加本地数据显示
3. **数据存储：** 添加SD卡记录历史数据
4. **远程控制：** 通过ESP8266接收远程控制指令
5. **阈值调整：** 添加按键或串口命令调整阈值
6. **OTA升级：** 实现远程固件升级

## 故障排除

1. **ESP8266连接失败：** 检查WiFi配置，确认串口波特率
2. **MPU6050无数据：** 检查I2C连接，确认地址配置（0x68或0x69）
3. **舵机不动作：** 检查PWM配置，确认电源供应
4. **报警不工作：** 检查LED和蜂鸣器连接，确认阈值设置
5. **数据上传失败：** 检查网络连接，确认服务器状态
