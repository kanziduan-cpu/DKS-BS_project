# APP 切换私有 EMQX 服务器配置手册（方案一 最简版）

## 架构说明
采用标准 MQTT 发布订阅广播模式，无需修改云端任何 PHP、EMQX 规则。
设备与 APP 共用同一个主题，消息自动广播，同时自动存入 MySQL 数据库。

## 1 云端状态
- EMQX 已开启匿名访问，无需账号密码
- 1883 端口已放行安全组+防火墙
- mqtt.php、数据库、规则引擎全部正常运行
- 云端**无需做任何修改**

## 2 MQTT 连接配置
服务地址：
```
tcp://47.83.152.62:1883
```

登录方式：匿名
- 用户名：留空
- 密码：留空

## 3 统一主题（固定不变）
### 设备发布 / APP 订阅 主题
```
warehouse/STM32_01/command
```

### APP 发送控制指令 发布主题
```
warehouse/STM32_01/command
```

## 4 数据通信格式
### 设备上传格式（APP 用来解析显示）
```json
{
  "device_id":"STM32_01",
  "temp":25.5,
  "hum":60.2
}
```
解析字段：
- temp：温度
- hum：湿度
- device_id：设备编号

### APP 下发控制指令格式
```json
{
  "device_id":"APP",
  "servo_angle":90,
  "buzzer_active":1
}
```

## 5 工作流程
1. STM32 往主题上报传感器数据
2. EMQX 自动分两路：
   - 一路推给 mqtt.php 写入 MySQL 数据库
   - 一路广播给所有订阅该主题的 APP
3. APP 实时接收 JSON，解析后显示温湿度
4. APP 向同一主题发控制指令，STM32 订阅接收并执行

## 6 常见问题
1. APP 连不上：检查 1883 端口是否放行、地址是否写错
2. 收不到数据：确认订阅主题完全一致，大小写符号不能错
3. 控制没反应：设备也要订阅同一个主题
